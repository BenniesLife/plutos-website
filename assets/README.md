# Pluto’s brand assets

The current, user-approved Pluto’s logo is **plutos-logo-2026-original.png**, supplied on 13 September 2026. Preserve this file unchanged as the master. It depicts Pluto with one blue eye and one brown eye, the white brush-lettered Pluto’s wordmark with a paw-shaped O, and the tagline **GOOD DOGS · GREAT TIMES** on black.

Use **plutos-logo-2026.webp** for the normal website. The older `plutos-logo.webp` and repository-root `logo.jpg` are legacy versions, retained for old links. Do not treat them as the current brand.

Seasonal editions must be separate files. A Halloween version is temporary and must preserve the dog’s identity, wordmark and tagline. Restore the normal 2026 logo when retiring the Halloween theme; never overwrite the master with a seasonal edit.
